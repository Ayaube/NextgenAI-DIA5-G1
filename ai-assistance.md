# AI assistance used for TD 1

This record documents assistance given to Aurélien Guillout-Lacomblez in the Codex chat for this project. It does not claim to describe other members' use of assistants. The experiment prompts sent to the five evaluated models are recorded separately in [prompts-en.md](prompts-en.md).

## Scope and checks

- Environment setup: guidance on Python, virtual environments, environment variables and the supplied access check. API keys were not included in the submitted files.
- References C16–C18: assistance drafting SQL and executing it on `data/boutique.sqlite` in read-only mode. A separate calculation on the supplied CSV files returned the same amounts: 376740, 258180 and 62480 cents. The subgroup's peer-check attribution is recorded in the SQL files and `reference-td1.csv`.
- Model B comparison: extraction of the final recorded results from `traces-B.csv`, with the required header and raw-trace pointers. The C02 explanation was checked against its SQL: the model selected birth years 2025–2026 instead of the required 2000–2001 window.
- Hand-in review: checks of reference-query execution, comparison rows, raw attempts, prompt fingerprints and repository documentation. Corrections covered the verified local environment versions, class/group identification, the explanation of completed age and LF line endings for hashed text files.

Assistance did not replace execution of the reference SQL or the raw provider traces. The group is responsible for verifying and explaining the submitted work. The requests below are transcribed from this conversation; they are the relevant requests for the SQL, comparison and final corrections, not a complete transcript of setup tutoring.
